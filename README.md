# 🧮 Calculadora de IVA España

Calculadora de IVA profesional y moderna para España con tipo impositivo del 21%.

## ✨ Características

- **Dos modos de cálculo:**
  - **Añadir IVA**: Calcula el IVA y total a partir de la base imponible
  - **Quitar IVA**: Calcula la base imponible a partir del total con IVA

- **Diseño moderno y profesional:**
  - Interfaz intuitiva y fácil de usar
  - Diseño responsive (móvil, tablet, escritorio)
  - Animaciones suaves
  - Gradientes modernos
  - Formato de moneda español (€)

- **Funcionalidades:**
  - Validación de entrada
  - Cálculo con tecla Enter
  - Resultados en tiempo real
  - Formato de números en español

## 🚀 Uso

Simplemente abre el archivo `index.html` en tu navegador web favorito.

### Añadir IVA
1. Selecciona la pestaña "Añadir IVA"
2. Introduce la base imponible
3. Haz clic en "Calcular IVA" o presiona Enter
4. Visualiza la base, IVA y total

### Quitar IVA
1. Selecciona la pestaña "Quitar IVA"
2. Introduce el total con IVA incluido
3. Haz clic en "Calcular Base" o presiona Enter
4. Visualiza la base imponible, IVA y total

## 📊 Tipo de IVA

Esta calculadora utiliza el **IVA general del 21%** aplicable en España.

**Nota:** En España también existen:
- IVA reducido: 10%
- IVA superreducido: 4%
